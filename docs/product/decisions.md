# 产品口径与已定决策

> 状态：稳定
> 适用版本：v0.1.8+
> 相关：product/requirements.md、architecture/domain.md、glossary.md

本文件记录「为什么这样做」，避免同一规则散落在多个页面。

---

## 1. 打卡状态

只有三种判定：

| 状态 | 含义 | 进入分母 |
|---|---|---|
| `done` | 已完成 | 是 |
| `missed` | 未完成 | 是 |
| `skipped` | 今天不做 | 否 |

历史版本曾有 `recorded`（只记录），v0.1.6 已移除：

- 值只是附加字段，不是状态
- 没有判定时写值自动记为 `done`
- 清空值只清 `value`，保留状态
- 旧 `recorded` 数据迁移为 `done`

## 2. 值（value）

- 任意短文本：`4`、`3min`、`4/3/2/2`
- 与状态独立写入，互不覆盖
- 有值时详细网格用值替换状态符号
- 挂件值 chip 可点击编辑；点击值不触发状态切换

## 3. 启用区间与每 N 天

- 任务可有多段区间；停用后再启用追加新段，不改历史
- 每段区间独立携带 `everyDays`
- `1` = 每天
- `N` = 以该段 `start` 为第 1 天，每 N 天出现一次
- 非周期日：今日不出现、网格格子禁用、统计分母排除
- 停用/重新启用时新段继承上一段 N

## 4. 今日进度与统计

- 进度分母 = 适用任务数 − skipped
- 近 30 天完成率分母 = done + missed
- skipped、不适用日期不进分母
- 自动结算只投影，不写库
- streak：done 计数，missed 中断，skipped / 空白 / 不适用不计数不中断

## 5. 网格交互

- 单击只聚焦，不写库
- 右键 / 双击打开格子编辑器
- 编辑器状态：完成 / 漏打 / 跳过 / 清除
- 保存顺序：状态 → 值 → 备注
- 概览点击回到详细并居中该日期
- `Ctrl + 滚轮` 缩放，`Shift + 滚轮` 横滚

## 6. 待办

- 分组：逾期 / 今天 / 本周 / 以后 / 已完成
- 无截止日归入「以后」
- 右键菜单可改日期、删除
- 行内日历按钮直接改截止日期
- 行内 ✎ 只改名字

## 7. 删除

- 所有删除入口必须二次确认
- UI 统一走 `ConfirmDeleteButton`
- store 删除方法要求 `DeleteConfirmation` 令牌
- 删除任务显式级联：checkins → intervals → tasks
- 失败保留确认框并显示错误

## 8. 侧栏顺序

- 顺序存 settings 表，不依赖 localStorage
- 拖动或 `Alt + ↑/↓` 调整
- localStorage 只做首屏缓存
- 旧 localStorage 顺序首次启动自动迁移
- JSON 导出 / 导入包含顺序

## 9. 语言

- 设置：跟随系统 / 中文 / English
- 默认跟随系统；英文系统自动英文，其余中文
- 日期、网格、挂件、统计、设置、托盘全部跟随
- 托盘静态文案由前端下发

## 10. 挂件

- 展开态与今日页同构，内部滚动
- 单击任务行按今日页循环状态
- 值 chip 行内编辑
- 右键 / `⋯` 状态菜单
- 无最小化按钮；隐藏走托盘

## 11. 明确不做

- 系统通知 / 到期提醒
- 云同步 / 账号
- 热力图、全局折线、按量统计
- 网格纵向虚拟化
- 降级更新（更新器不支持）
