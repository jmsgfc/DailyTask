# 故障排查

> 状态：稳定
> 适用版本：v0.1.8+
> 相关：development/debugging.md、operations/backup.md

---

## 启动

| 现象 | 处理 |
|---|---|
| 白屏 | 看 Console `[init]`；确认 DB 未被占用；检查迁移 |
| 启动即退出 | 可能是单实例：已有一个 DailyTask 在跑，会唤回主窗 |
| 窗口透明/发黑 | 检查 Windows 透明窗口与 DPI；先用 100% 缩放复现 |
| 开发版与安装版数据不同 | 正常：identifier 不同 |

## 数据库

| 现象 | 处理 |
|---|---|
| `database is locked` | 退出另一个实例；结束残留 exe；必要时删 `-wal`/`-shm` |
| 迁移失败 | 先备份 DB；检查 `src-tauri/migrations` 版本顺序 |
| 旧数据少/状态异常 | 确认 004 是否执行；旧 `recorded` 应变成 `done` |

## 托盘

| 现象 | 处理 |
|---|---|
| 托盘图标不见 | 任务栏溢出区；重启应用 |
| 菜单文案不切换 | 检查 `set_tray_labels` 与语言设置 |
| 左键无反应 | 左键应同时唤回主窗与挂件；确认主窗未被最小化/隐藏，托盘事件绑定正常 |

## 挂件

| 现象 | 处理 |
|---|---|
| 尺寸不对 | 200% DPI 下逻辑仍 260×360；检查边距 |
| 拖动后不回边 | 松手触发 `snapCapsule`；检查屏幕工作区 |
| 单击任务状态不变 | 确认点击落在行上而非输入框 |
| 值改不了 | 确认点击的是值 chip；Enter / 失焦保存 |

## 更新

| 现象 | 处理 |
|---|---|
| 检查更新失败 | 网络 / 代理；`latest.json` 是否可访问 |
| 安装后没重启 | 更新器限制；手动启动 |
| 私钥丢失 | 无法再推更新，只能手动重装 |
| 想降级 | 更新器不支持；按升级回退文档手动装旧版 |

## 删除

| 现象 | 处理 |
|---|---|
| 点删除没反应 | 确认弹窗是否出现；store 是否收到确认令牌 |
| 删除失败 | 看 `[delete]` 日志；数据库是否被占用 |
| 删除后统计没变 | 任务已删；回到今日/统计刷新 |

## 收集信息

- 应用版本：设置页当前版本
- 数据目录：见 `development/setup.md`
- Console 完整错误
- 最近一份备份文件名
