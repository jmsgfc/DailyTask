## 1. 语言档

```ts
type Language = "system" | "zh-CN" | "en";
type ResolvedLanguage = "zh-CN" | "en";
```

设置默认 `language: "system"`。

解析规则：

- `system` + `navigator.language` 以 `en` 开头 → `en`
- 其他情况 → `zh-CN`
- 目前只有中英两套完整字典，其他系统语言回退中文

## 2. 文件

| 文件 | 职责 |
|---|---|
| `src/shared/i18n/zh-CN.ts` | key 的唯一定义处 + 中文 |
| `src/shared/i18n/en.ts` | 英文；类型为 `Messages`，漏 key 编译失败 |
| `src/shared/i18n/index.ts` | 注册、`resolveLanguage`、`setLocale`、`t`、`dateLocale` |
| `src/ui/useT.ts` | `useT()` / `useLocale()` |

## 3. 行为

```ts
setLocale(language)           // system 在这里解析
getLocale(): ResolvedLanguage
t(key, vars?)
dateLocale(language)
```

- `setLocale` 同步 `document.documentElement.lang`
- 语言变化通过 `subscribe` 通知 `useT` / `useLocale` 重渲染
- `dateLocale` 用于 date-fns 的星期 / 月份文案
- 插值统一 `{name}`，不要在句子里拼变量

## 4. 设置页

外观区：

```text
语言  [跟随系统] [中文] [English]
```

- `data-language-option="system|zh-CN|en"`
- 点击立即 `setLocale`，再写 `settings.language`
- 跨窗口通过 `settingsChanged` 同步

## 5. 托盘

Rust 不内嵌完整语言包，只保存前端下发的文案：

```ts
invoke("set_tray_labels", {
  showMain, hideMain, showWidget, hideWidget, quit,
});
```

- `useTrayLabels` 在 locale 变化时重新下发
- `useTrayProgress` 的 effect 依赖 locale，进度文案也同步
- `sync_tray_labels` 根据窗口可见性在「显示/隐藏」之间选文案

## 6. 新增语言

步骤见 [how-to/add-a-language.md](../how-to/add-a-language.md)。`Messages` 类型会在 `typecheck` 时列出缺失 key。

## 7. 英文布局注意

- 挂件任务名、值 chip 都可能截断，保留 `truncate`
- 设置页 `SettingRow` 标签宽 240px，长 hint 允许换行
- 任务管理操作列 190px，最多 3 个动作
- 日期格式跟随 date-fns locale，业务存储始终是 ISO
