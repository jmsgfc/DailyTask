# 后续规划

> 类型：解释
> 状态：迭代中
> 适用版本：v0.1.9+
> 相关：explanation/product-decisions.md、project/backlog.md

不是承诺清单，只是候选方向。优先级以用户反馈为准。

---

## 1. 近期候选

| 方向 | 价值 | 备注 |
|---|---|---|
| 挂件数值输入历史 | 快速补记 | 当前只编辑当天 |
| 统计按值聚合 | 次数 / 时长趋势 | 需要定义值的解析规则，暂不做 |
| 网格备注搜索 | 找回历史上下文 | 先评估数据量 |
| 多语言扩展 | 日 / 繁中 | 需第三方翻译校对 |
| 主题自定义 | 个性化 | 先保持 token 体系 |

## 2. 暂不做

- 云同步 / 账号：与本地优先冲突
- 系统通知：权限与免打扰复杂
- 热力图 / 全局折线：统计口径先稳定
- 移动端：只支持桌面
- 更新降级：更新器不支持

## 3. 技术债

- 英文长文案的视觉回归还没有自动截图
- `docs:check` 只校验链接与状态头，不校验命令可执行
- 任务表 1000 列性能只在测试与人工走查中验证，没有 CI 基准
- 备份恢复目前只有文档，没有应用内一键恢复

## 4. 发布节奏

- 反馈批次 → 修复 / 功能 → 全量测试 → `v0.1.x` 发布
- 破坏性数据变更必须带迁移 + 兼容旧 JSON
- 迁移脚本只追加，禁止改历史
