# 第一次使用 DailyTask

> 类型：教程
> 状态：稳定
> 适用版本：v0.1.9+
> 相关：reference/checkins.md、how-to/daily-use.md

跟着本文走一遍，你会得到一个可用的每日任务、一条今日打卡、一个待办，并看到统计结果。

---

## 1. 安装并打开

1. 打开 [GitHub Releases](https://github.com/yearzen1/DailyTask/releases/latest)。
2. 下载 `DailyTask_x.y.z_x64-setup.exe`。
3. 双击安装，选择当前用户安装。
4. 启动 DailyTask。首次启动会同时出现主窗口和悬浮挂件。

预期：主窗口左侧看到「今日 / 任务表 / 待办 / 任务管理 / 统计 / 设置」。

## 2. 新建第一个每日任务

1. 点击左侧「任务管理」。
2. 点击右上角「＋ 新任务」。
3. 名称填「喝水」，类型选「自愿」。
4. 启用日期保持今天。
5. 间隔天数保持 `1`（每天）。
6. 点击「创建」。

预期：表格出现「喝水」，状态「进行中」，启用日期是今天。

## 3. 今日打卡

1. 点击左侧「今日」。
2. 找到「喝水」。
3. 点击任务行左侧方框。

预期：方框变成 `✓`，进度环和「已完成 1 / 1 项」更新。

再点一次同一行：

- 第一次点击后状态是 `✓`
- 再点变成 `✗`
- 第三次点击清除

## 4. 在任务表里看历史

1. 点击左侧「任务表」。
2. 找到「喝水」行。
3. 今天列应该显示 `✓`。
4. 右键或双击其他日期格子，可以补记、改状态、写备注。

预期：今天列高亮，任务行左侧固定，日期可以左右滚动。

## 5. 建一个待办

1. 点击左侧「待办」。
2. 在顶部输入「交房租」。
3. 截止日期选今天。
4. 按回车或点「添加」。

预期：「交房租」出现在「今天」分组；今日页底部也会出现「今日到期待办」。

## 6. 看统计

1. 点击左侧「统计」。
2. 找到「喝水」。
3. 看「当前连续」和「近 30 天」。

预期：完成一次后，连续天数和完成率有数值。

## 7. 试一次挂件

1. 看桌面上的悬浮挂件。
2. 单击任务行：状态循环。
3. 点击值 chip：可以记录 `1`、`30min` 等值。
4. 右键任务行：完成 / 未完成 / 跳过 / 清除。

预期：挂件和主窗数据同步。
