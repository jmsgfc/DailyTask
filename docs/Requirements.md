# DailyTask 设计稿

> 支持每日任务打卡 + 待办事项的桌面应用（仅电脑端）。
> 本文档聚焦 **UI / 交互 / 数据模型** 设计，技术栈待定。

---

## 1. 背景与目标

### 1.1 要解决的痛点

用户当前用 Excel 记录每日打卡，流程是：建表头（日期 + 每日任务），每行一个日期，打勾打叉，再用冻结窗口固定表头。痛点：

| # | 痛点 | 根因 |
|---|---|---|
| 1 | 想调整每日任务，又不想改动历史数据，只能新建表头并复制旧表头 | **表结构（表头）和数据耦合在一张表里，没有版本概念** |
| 2 | Excel 不会自适应，需要手动调列宽 / 缩放 | 网格没有内建的自适配规则 |
| 3 | 每次新建表头都要重设冻结窗口 | 冻结是"每张表的属性"，而非网格本征行为 |

### 1.2 设计目标

1. **结构层面消除三个痛点**，而不是做一个"更好看的 Excel"。
2. 每日打卡要**极低摩擦**：悬浮卡片上就能勾。
3. 历史数据**永不丢失、永不需手工维护**，且一眼回看。

### 1.3 非目标（当前不做）

- 多端同步、账号体系（先本地单机；数据层预留扩展）。
- 优先级、标签、子任务、团队协作等重型 todo 功能。
- 移动端 / Web 端。

---

## 2. 核心设计决策

### 决策 1：取消「表头」概念，改为「任务的启用区间」

不再有"表头"这个对象。**每条每日任务自带一个或多个「启用起止日期」**：

- 想新增任务 → 加一条任务，启用日期默认今天。
- 想让某任务不再当每日任务 → 给它设置停用日期（而非删除、更不是复制表头）。
- 旧数据自动保留、自动置灰，永久可查。

> 这就把"改表头"从**结构性操作**降级为**数据操作**，痛点 1 消失。

### 决策 2：任务表用「日期做列、任务做行」

理由：每日任务通常只有 5～15 条，但日期会累积到几百天。

- 一屏即可看到**全部任务**（行少），只需横向滚动时间。
- 加任务 = 加一行，顺手。
- 与主流习惯追踪（GitHub 贡献图、Habitica）一致。

对比：

| | 日期做列 + 任务做行（采用） | 日期做行 + 任务做列（Excel 习惯） |
|---|---|---|
| 看全部任务 | ✅ 一屏可见 | ❌ 任务多要横向滚 |
| 加新任务 | 加一行 | 加到最右列，需滚过去 |
| 看某任务历史 | 看一行，直观 | 看一列 |
| 看某天做了什么 | 看一列 | 看一行 |

### 决策 3：双形态窗口

- **悬浮小卡片**（常驻置顶、纸感）：默认态，显示今日打卡进度，可直接勾选，点击展开主窗口。
- **主窗口**（现代极简、信息密度高）：左侧导航 + 右侧内容区。

两套皮肤共用同一色板。

---

## 3. 信息架构

```
悬浮小卡片 ──点击展开──▶ 主窗口
                           ├─ 今日           (默认首页)
                           ├─ 任务表         (核心，替代 Excel)
                           ├─ 待办
                           ├─ 任务管理       (原"表头管理")
                           ├─ 统计
                           └─ 设置
```

- **今日**：高频入口，打卡 + 今日到期待办。
- **任务表**：低频，回看与补齐历史。
- **任务管理**：维护任务清单与启用区间（日常几乎不用进）。

## 4. 界面设计

### 4.1 悬浮小卡片（默认态）

纸感便签，无边框、圆角、柔和阴影、常驻置顶。

```
┌────────────────────┐
│  今日 · 10/18    🌤 │
│                    │
│        ◕ 4 / 6     │   ← 进度环
│                    │
│  ☑ 早起   ☐ 跑步   │
│  ☑ 背单词 ☐ 交周报 │   ← 直接点击勾选
│  ○ 交房租  逾期2天  │   ← 今日到期待办
│                    │
│      展开详情 ▸     │
└────────────────────┘
```

- 只显示未完成项 + 今日到期待办；已完成的折叠为一行 `☑ 4 项已完成`。
- 勾选即时写库，小卡片本身即完成打卡。
- 悬停出现「展开 / 最小化 / 钉住」小按钮。

### 4.2 今日视图

```
┌ 今日 · 10/18 周六 ──────────────┐
│         ◕ 4 / 6                │   进度环
├────────────────────────────────┤
│ 自愿任务                        │
│  ☑ 早起        ☐ 跑步          │
│  ☑ 背单词                      │
│ 被迫任务                        │
│  ☑ 开会        ☐ 交周报        │   ← 可标"今天不做"
├────────────────────────────────┤
│ 今日到期待办                    │
│  ○ 交房租   🔴 逾期 2 天        │
│  ○ 买猫粮   🟡 今天            │
└────────────────────────────────┘
```

- 自愿（绿）/ 被迫（灰蓝）用**颜色 + 分组**区分。
- 支持「今天不做」：当天记为不适用，不算未完成（区别于 ✗）。

### 4.3 任务表（核心）

**日期做列（顶部常驻），任务做行（左侧常驻），按类型分组。**

```
              │ 10/12 10/13 10/14 10/15 10/16 10/17 10/18   ← 日期行
─── 自愿 ─────┼────────────────────────────────────────────
  早起        │  ✓     ✓     ✗     ✓     ✓     ✓     ✓
  跑步        │  ✓     ✗     ✓     ✓     ▫     ▫     ▫      (停用 10/15)
  背单词      │  ▫     ▫     ▫     ▫     ✓     ✓     ✓      (启用 10/16)
─── 被迫 ─────┼────────────────────────────────────────────
  开会        │  ✓     ✓     ✓     ✓     ✓     ✓     ✓
  交周报      │  ✓     ✗     ✓     ✓     ✓     ✓     ✓
── 已停用 ────┼────────────────────────────────────────────   ← 默认折叠
  跳绳        │  ✓     ✓     ▫     ▫     ▫     ▫     ▫
```

单元格状态：

| 符号 | 含义 |
|---|---|
| `✓` | 完成 |
| `✗` | 未完成 |
| `▫` | 该任务在该日期尚未启用或已停用（灰、不可点） |
| 空格 | 当天未记录（见 5.x 自动结算规则） |

顶部时间标尺：在每次批量启用/停用任务处打小标记，悬停显示 `10/16 起：+背单词 / −跑步`。**仅为标注，不是数据结构。**

**两种缩放模式**（`Ctrl + 滚轮` 连续缩放）：

```
【详细模式】近 2 周，格子大，带日期
  10/12 10/13 10/14 10/15 ...
   早起  ✓     ✓     ✗     ✓
   跑步  ✓     ✗     ✓     ✓

【概览模式】整年，格子小，像贡献图
  早起  ▓▓▓░░▓▓▓▓▓░▓▓▓▓▓▓▓░░▓▓▓ ...
  每格 = 1 天；颜色深浅 = 完成率；点击可放大到详细模式
```

### 4.4 待办事项

只有两个核心字段：**截止日期 + 任务**。自动分组，不引入优先级/标签。

```
逾期  ●  交房租           10/16  🔴
今天  ○  买猫粮           10/18  🟡
本周  ○  预约体检         10/21
以后  ○  换灯泡           —
已完成 ✓ 写周报            10/17
```

- 行内直接勾选完成；右键改日期 / 删除。
- 逾期项左侧红色条 + 天数；无截止日期归入「以后」。

### 4.5 任务管理（原「表头管理」）

任务清单表格，日常很少进：

| 任务 | 类型 | 启用日期 | 停用日期 | 操作 |
|---|---|---|---|---|
| 早起 | 自愿 | 2026-10-01 | — | 停用 / 编辑 |
| 跑步 | 自愿 | 2026-10-01 | 2026-10-15 | 重新启用 / 编辑 |
| 背单词 | 自愿 | 2026-10-16 | — | 停用 / 编辑 |

- 「＋ 新任务」：填名字 + 类型，启用日期默认今天。
- 停用/重新启用会追加区间，历史数据不受影响。

### 4.6 统计

- 单任务：当前连续天数（streak）、近 30/90/365 天完成率、热力图。
- 全局：每日完成率折线、自愿 vs 被迫完成率对比。

### 4.7 设置

主题（浅/深/跟随系统）、自动结算开关、一天的起始时间、开机自启、置顶开关、数据导入/导出。

## 5. 交互规则

- **单击格子**：`空 → ✓ → ✗ → 空` 循环（单键走完，比右键易记）。
- **悬停格子**：`✓`/`✗` 上出现气泡，可加当天备注（如"只跑了 1km"）。
- **今天竖线**：当前日期列高亮。
- **列/行操作**：任务行可拖动排序、可折叠分组；已停用任务默认收进「已停用」区。
- **筛选**：顶部可按「自愿 / 被迫」、单个任务、时间段过滤。
- **键盘**：`←/→` 切日期，`↑/↓` 切任务，`Space` 切换当前格状态。

### 5.1 自动结算规则（默认假设，可在设置里关）

- **当天及未到来的日期**：未打勾 = 空格（尚可完成）。
- **已过去的、且该任务适用的日期**：未打勾自动显示为 `✗`（未完成），用于得到诚实的完成率；仍可点击改成 `✓`。
- **一天的起始时间**默认 `04:00`：凌晨熬夜补打卡仍算前一天（习惯类应用常见做法）。

## 6. 数据模型

本地存储（默认 JSON 文件，可平滑迁移到 SQLite）。所有记录带 `id / createdAt / updatedAt`，为将来同步预留。

```jsonc
// 每日任务
Task {
  id: string,
  name: string,
  category: "voluntary" | "forced",      // 自愿 / 被迫
  intervals: [{ start: "YYYY-MM-DD", end: "YYYY-MM-DD" | null }],  // 启用区间，可多段
  order: number,
  createdAt: string,
  updatedAt: string
}

// 打卡记录（一格一条）
Checkin {
  id: string,
  taskId: string,
  date: "YYYY-MM-DD",
  status: "done" | "missed" | "skipped",  // ✓ / ✗ / 今天不做
  note?: string,
  updatedAt: string
}

// 待办
Todo {
  id: string,
  title: string,
  dueDate: "YYYY-MM-DD" | null,
  done: boolean,
  completedAt: string | null,
  createdAt: string,
  updatedAt: string
}

// 设置
Settings {
  theme: "light" | "dark" | "system",
  gridZoom: number,
  autoSettleMissed: boolean,   // 默认 true
  dayStartHour: number,        // 默认 4
  alwaysOnTop: boolean,
  autoLaunch: boolean
}
```

**派生逻辑**

- 任务在日期 `d` 是否适用：存在区间满足 `start ≤ d ≤ (end ?? +∞)`。
- 某日进度 = 该日适用任务数中 `status == "done"` 的占比。
- 空格在展示时按 §5.1 规则投影为 `✓ / ✗ / 空`。

## 7. 视觉规范

### 7.1 主窗口（现代极简）

| 用途 | 浅色 | 深色 |
|---|---|---|
| 背景 | `#FAFAFA` | `#1E1E1E` |
| 卡片/表面 | `#FFFFFF` | `#262626` |
| 边框 | `#E5E5E5` | `#3A3A3A` |
| 主文字 | `#1A1A1A` | `#F0F0F0` |
| 次文字 | `#8A8A8A` | `#9A9A9A` |
| 自愿 / 完成（绿） | `#3D9A62` | `#4CAF7D` |
| 被迫（灰蓝） | `#6B7A99` | `#8CA0C4` |
| 未完成（红） | `#D9534F` | `#E06C68` |
| 不适用（灰） | `#EDEDED` | `#333333` |

### 7.2 挂件（纸感）

- 纸底 `#FBF7EF`，柔和阴影，圆角 `16px`，轻微纸纹。
- 标题可用楷体/手写体，正文用无衬线保证可读。

### 7.3 通用

- 字体：系统无衬线（苹方 / 微软雅黑 / 思源黑体）。
- 间距刻度：`4 / 8 / 12 / 16 / 24`。
- 圆角：`6`（控件）/ `10`（卡片）/ `16`（挂件）。
- 网格单元格尺寸由缩放级别决定，内容自适应，无需手调。
