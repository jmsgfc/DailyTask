# 切换语言

> 类型：操作指南
> 状态：稳定
> 适用版本：v0.1.9+
> 相关：reference/i18n.md、how-to/add-a-language.md

适用：把界面切到中文 / English，或改回跟随系统。

---

## 1. 切换

1. 打开「设置」。
2. 外观区找到「语言」。
3. 选择「跟随系统 / 中文 / English」。

切换立即生效，不需要重启。

## 2. 跟随系统

- 英文 Windows → 自动英文
- 其他语言 → 回退中文
- 当前只提供 zh-CN / en 两套完整字典

## 3. 会跟随的部分

- 所有页面文案
- 日期星期 / 月份
- 今日、挂件、网格、统计、设置
- 托盘菜单与今日进度

## 4. 验证

- 设置页立即变化
- 挂件和主窗一致
- 托盘右键文案变化
- 重启后保持所选语言

## 5. 常见问题

- 语言没变：确认点的是「语言」，不是「主题」
- 托盘还是旧语言：切换后等一次渲染；仍不对看排障文档
- 英文长文案溢出：记录页面与宽度，提交问题
